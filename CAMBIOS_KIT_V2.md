# Cambios del kit — Revisión 1.1

Fecha de la revisión: 19 de septiembre de 2026. No es una versión del programa.

## Interfaz más fácil de encontrar y comprobar

Se conserva `docs/DESIGN_SYSTEM.md`, que ya contenía la guía visual. Se añade `docs/INTERFAZ.md` con pantallas, flujos y estados, un índice en `docs/README.md` y un inventario ampliado de controles. La fase 02 y la auditoría visual exigen consultar los tres documentos.

## Repositorio nuevo y control de versiones

El primer mensaje ahora se dirige a Astra y encarga crear/verificar `sredgarr/IDG`. El título es `IDG — Internet Download Genious`. La visibilidad propuesta en ese mensaje es pública. El kit no ha consultado ni creado el repositorio: son tareas de Astra con acceso autorizado.

Se añade `docs/GITHUB_WORKFLOW.md`, se modifica fase 00 y se reemplazan las instrucciones anteriores que bloqueaban todo push. La autorización se limita a fuente/documentación de IDG; releases, tiendas y acciones destructivas permanecen separadas.

## README para usuarios

Se añade una portada README.md comprensible, con estado real y funciones previstas. Instalación y desarrollo tienen guías separadas. Se prohíbe inventar un instalador, una versión publicada o capturas del programa antes de que existan.

## Coherencia

Se actualizan AGENTS, especificación, arquitectura, estado, pruebas, fuentes y cierre de todos los prompts. Se conservan las 16 fases principales, 2 opcionales y 3 de mantenimiento. Se añaden exclusiones Git iniciales. Ninguna función se marca como implementada por esta revisión documental.
